# R15 封存后的 BRAM 压缩构思

## 基线与边界

最终真实布局布线占用 314/340 个 BSRAM，比 R13 的 286 多 28，剩余 26 个。不能用综合层级报告中的小提琴 17 个逻辑存储实例冒充实际物理增量。

本版已通过正式时序，但最差 Setup 仅 +0.018 ns。当前不改通过版；以下都必须放入另一个实验工程，逐项对拍、真实综合及布局布线后才可认定节省。

不降低弦波导的 24 位精度，不降低声体 Q30 状态精度，不通过清空尾音或静音门掩盖量化噪声，也不把弓弦反馈环路直接移入具有不确定访问延迟的 DDR。

## 实验顺序

1. **先试小 ROM 的实现方式。** FIR 只使用对称前半段 48×24 bit 系数，容量 1,152 bit；独立探测逻辑 ROM 与 BSRAM 的真实映射。若改为逻辑查表，必要时增加一个系数预取寄存级，不能把长多路器直接接进乘法器。潜在节省以物理报告为准。
2. **串行读取音高/力度参数。** 当前两张控制表为了单拍取出多个字段采用较宽存储。控制事件只在音符切换时查表，可以把同一条记录分成窄字连续读取，多用几个控制时钟换取更好的 RAM 宽深配比；不要改变查表数值。须验证 Hall 六路突发与队列容量。
3. **复用摩擦/揉弦的双读 ROM。** 当前每次插值同时读相邻两个点。考虑单端口顺序读两次，减少重复 ROM；增加的状态必须计入最短帧预算。当前完整运算为 852/1041 clocks，有 189 clocks 账面空间，但需保留事件处理及边界余量。
4. **最后评估小提琴存储池化。** 两段波导与 FIR 历史合计 `(512+128+128)×24=18,432 bit`，逻辑容量不大，物理浪费主要来自位宽/端口适配。可研究 R13 已用过的 72 位三采样打包思路，但这里存在分数延迟双读、单点写入及 FIR 两头读取，必须设计读改写与调度，不能直接照搬播放 RAM。先做独立 RAM 探测，证明是否实际节省后再接入声部。

## 每次实验的门槛

- 与封存模型逐点一致，或对明确允许的数值变化另立声学指标；不默认接受降精度。
- 31,000 帧完整小提琴对拍、全音域极端力度数值测试、控制边界与整机 DAC 回归。
- 所有原时钟、Gray 指针最大延迟、DAC 输出约束及最小脉宽检查继续有效，Setup/Hold 不能新增违规。
- 记录实际物理 BSRAM 增减、DSP/LUT 代价和最差时序余量，不只比较 RTL 数组大小。

这些是下一轮方案，不是已经取得的 BRAM 节省。由于本版时序余量较小，扩大余量与硬件试听应先于激进的存储池化。
