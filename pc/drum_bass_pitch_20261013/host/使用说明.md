# Tang Mega 上位机 · 单窗口现场验证整合版

更新：2026-10-10。新增第六页“现场验证与视听”，支持 1–4 路 FPGA DDS、真实板端采样回传、波形、频谱和李萨如显示。新增功能必须烧录本次工程生成的 `guitar_audio_verification.fs`，并连接 FPGA TX P15 到 USB 串口 RX；旧位流只支持原五页功能。完整操作及验收步骤见交付目录的 `00_分析与使用说明.md`。离线预览不能作为上板验证证据。

版本：2026-10-07 / 浅蓝 A 方案，橙色、青绿、紫色辅助配色。

## 启动

双击本文件夹内的 `run_gui.bat`。可直接替换原工程的 host 文件夹，也可单独放置使用。
保留整个 host 文件夹的文件结构。原五页功能可继续使用旧位流；新增现场验证功能需要本次新位流。
使用原来已经能运行上位机的 Python 环境即可。
如缺少依赖，在 host 文件夹打开终端，执行：

```powershell
python -m pip install -r requirements.txt
python guitar_controller.py
```

## 页面调整

- 左侧保留原五个页面并新增“现场验证与视听”。
- 所有功能页面都在主窗口内切换，不再打开独立功能窗口。
- 删除吉他页“钢琴快捷控制”卡片、独立“手绘包络”导航入口和吉他页重复入口。
- 原钢琴页的手绘波形、手绘包络、起音区放大、时长、预设、平滑、保存、载入、双表上传、恢复原钢琴全部保留。
- 88 键演奏、力度、踏板、跳转八度和琴键横向滚动全部保留。
- 演奏混音、合唱、延迟合并在“混音与空间效果”中；三路总线音量、静音、平衡预设、自动平衡和两种空间效果都可调节。
- 当前资料没有已实现的混响算法或控制协议；同页预留混响区域并明确显示“待接入”，未添加无效滑块或虚构指令。
- 页面切换保留设置与手绘曲线，鼓机和 Riff 可继续播放；离开钢琴页自动松开正在按住的琴键。
- 鼓机右键细分编辑改为页内编辑，仍为 1 / e / & / a 四个十六分音符力度。
- 运行中的连接/参数错误改为主窗口内提示；保存和打开文件仍使用系统文件选择器。
- 小窗口通过页面纵向滚动显示全部操作；吉他指板、钢琴键和鼓机节奏格保持各自横向滚动。

## 验证

原有 46 项测试及新增 7 项页面整合回归，共 53 项全部通过。
核对了现有音频参数、串口帧、Riff、鼓机时序及钢琴绘图/上传方法。
实际程序已在 1440×900 和 980×660 两种窗口尺寸检查，未发现按钮挤压或界面回调异常。
鼠标拖动混音滑块已验证，实际输出仍为原 0x70 总线音量协议；合唱/延迟仍为 0x60/0x61/0x62。
本次为软件和模拟串口验证，未连接板卡进行实机声音试听。

`验证记录/自动测试.txt` 为测试输出；`界面预览` 为实际 Tk 程序截图。
`presets/hard_rock_riff_drums.json` 保留铁轨 Riff 配套鼓机节奏，可在鼓机页面载入。
