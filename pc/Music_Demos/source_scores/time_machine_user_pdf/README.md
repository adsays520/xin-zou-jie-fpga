`time_machine_score.py`是双手可编辑工作转谱：音名已包含降号及实际高八度；`^`表示琶音和弦，`~`表示同音连线，时值单位为八分音符。保留主段三连音、明确的还原D音、高八度段和最终连音。对于图像中不够明确的装饰间距作了器乐演奏量化，不作为校订版乐谱或原录音逐音复刻。
