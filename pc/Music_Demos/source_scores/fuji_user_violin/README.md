# 《富士山下》提琴谱来源参考

**最新决定（2026-10-27）**：用户要求钢琴主奏、提琴连续衬托，同时指出纯持续音没有曲调。当前工程`p06_fuji_pad`已改为轻声连弓的旋律伴行：用这份提琴谱的匹配乐句和钢琴旋律补全，保留曲调、附点、同音连线和末尾三连音；用连弓而不是反复松音来连接。当前代码是`fuji_violin_pad.py`的`SCORE_WINDOWS`，并非下文已归档的插句实验。

`page_1.png`、`page_2.png`原样保存用户提供的两页提琴谱。谱面为F大调，开头8小节休止，含反复、第一/第二结尾，末尾有3/4、三连音、延长与渐慢。

本次不是把67个谱面小节完整重复播放，也没有把这份旋律谱称为原唱的弦乐分轨。`fuji_violin_score.py`只转录再编配使用/核对的选段；`fuji_score_bow.py`保存每个选段到钢琴工程的乐句映射。原谱的8小节休止不能直接套到另一份45小节的钢琴改编谱上。

钢琴仍采用用户先前PDF的工作转谱。以两谱共同的C4拾音、G4-A4起句及副歌下降片段对齐：部分主段存在六拍的起句偏移；并非所有小节都适用同一偏移，因此选段逐项映射。保留选段的实际音高、附点和同音连线，部分副歌只降八度；省略的片段给钢琴留白。

新增前奏和声从钢琴第2小节第3拍进入，按Dm、Am、Bb、C、F的伴奏变化落音，与提琴谱原有休止区明确分开。其后主段约隔几个小节加入，副歌略增加；提琴不一直叠唱钢琴旋律。

完整版维持钢琴工程47小节/94秒，包括尾音；短版为钢琴谱第28–33小节和2小节收束，16秒。由于采用钢琴版结构，提琴谱的反复和最后3/4小节没有完整移植；没有假称已支持变拍号或渐慢自动化。收束的F音参考提琴谱末尾。
