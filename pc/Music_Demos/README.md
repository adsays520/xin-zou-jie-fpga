## 新增：失真电吉他主导《钢铁公路》

- E小调，136 BPM，40小节约70.6秒；短版约14.1秒，保留副歌再现和落地结尾。
- 七条逻辑轨：低弦Riff、强力和弦、主音/独奏、Bass、底鼓军鼓、镲片、过门。钢琴与小提琴完全不参与、对应总线为0。
- 结构：4小节引子 → 8小节Riff主题 → 8小节副歌 → 4小节间奏 → 8小节吉他独奏 → 6小节副歌再现 → 2小节尾声。
- 使用现有 **JCM800风格失真（amp=3）**，drive=72、tone=48、效果level=64、mix=127全湿；箱体开启，噪声门开启且阈值18，压缩与调制关闭。
- 吉他总线初值48，高于Bass的31和鼓的30；独奏段进一步突出吉他，空间延迟保持少量，不把失真主体淹在回声中。
- 强力和弦采用根音、五度、八度，而非密集九和弦；独奏旋律单独编写，不是把原小提琴轨换个音色。
- 三条吉他轨共用一个吉他效果链，不是三套独立箱头；这里的名称是合成音色风格，并非真实电路/拾音器录音复刻。
- 当前协议没有吉他逐音精确截音，时间轴短矩形只表示编排门长，**不代表真实掌根闷音**。通过稀疏Riff、强弱变化、和声简化及尾声总线渐弱控制层次，不为这首曲修改FPGA。
- 失真容易主观上更响，先降低音箱音量试听短版。本次不自动播放、不烧录，最终音色与平衡仍需在板上试听。

## 板上发声

1. 使用已通过时序的 `ensemble_daw_v10` 位流，不需要为这些Demo重新综合、烧录或修改ESP。
2. 工作台右上角连接 **FPGA的UART串口**（此前为COM11，以当前实际枚举为准），不是S3霍尔页的COM30。
3. 在编曲工作台保持“独立多乐器”选中，点击“探测v8能力”。v10沿用v8多乐器协议，这个按钮名不表示要烧回v8。
4. 等待能力探测成功、钢琴采样库就绪，然后勾选“发送到FPGA”，点播放；有安全提示时按提示处理，不要绕过。
