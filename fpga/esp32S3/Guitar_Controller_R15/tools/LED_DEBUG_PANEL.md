# v3.4.24 展示入口

点击“赛博展示”让两路持续青紫玫红动画；默认亮度32/255。新版固件上电自动展示，关闭新版调试窗口会请求恢复展示。已打开的旧窗口需重开才生效。纯跟灯和停止关灯按钮仍可用。

# LED颜色与闪烁调试

双击工作区根目录的“打开LED调试.cmd”，选择S3原生USB COM30，点击连接。请关闭其他占用同一串口的程序。已配套烧录S3 v3.4.20；本工具不烧写固件，也不发送音符。

1. 选择GPIO3（14颗）、GPIO7（13颗）或两路。
2. 选择数据速率：714kHz试验、800kHz 350/900ns，或800kHz厂家典型值。
3. 设置RGB颜色与亮度。建议初次用10%亮度；0%就是关灯。连接后的快捷颜色按钮会立即应用当前设置。
4. 不勾选闪烁即常亮；勾选后可设0.1～10Hz、10～90%亮灯占比，点击“应用输出”。1Hz/50%代表亮0.5秒、灭0.5秒。
5. “停止并关灯”清除两路输出；“恢复按键跟灯”返回普通演奏灯效。正常断开或退出也会请求关灯。

闪烁由S3本地计时，LED任务约10ms调度一次，边沿存在调度量化，不是精密测量信号源。714/800kHz是每一位数据的传输速率，与灯光闪烁Hz是两个独立设置。正常连接不会自动切换输出。

下方显示板端回读与命令日志。板端确认仅代表接收了参数，不能替代实际灯珠颜色和级联效果验收。若连接意外丢失，板端可能继续保留最后的本地测试，重新连接后可点击停止。

协议：LED,OUTPUT,pin,R,G,B,period_ms,on_ms。线上RGB不先换成GRB，换序由S3统一完成。例如LED,OUTPUT,3,32,0,0,1000,500表示GPIO3红色32/255、1Hz、50%占比。LED,OUTPUT,STATUS读取当前设置。LED,MODE,OFF停止并关灯。

发送编码可选“整帧字节 · 新版”（默认）或“手工符号 · 旧版对照”。两种方式使用相同颜色、引脚和速率，便于单独对比编码路径。切换后点击应用输出。
